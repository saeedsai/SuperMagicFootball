# Closed-mouth definition polish

## Scope

Improved the contrast and weight of the existing closed-mouth contour in `CHARACTER_ART.lips()` for options that use the closed-mouth branch. The face geometry, style placements, profile/quarter transforms, open-mouth options, and hurt/cry rendering remain unchanged. This is a renderer polish prototype; it has not received owner visual approval.

Acceptance criteria:

- Closed-mouth styles have a clearer game-size contour in front, quarter, and profile projections.
- Existing open-mouth, hurt, and cry branches keep their current behavior.
- The actual game renderer renders the full mouth-option gallery without blank/clipped sprites or browser errors.

## Change

- Main closed-mouth fill alpha: `0.53` → `0.64`.
- Outer contour stroke: `1.55` → `1.8` px.
- Lower-lip highlight: alpha `0.70` → `0.84`, width `0.9` → `1.1` px.
- No facial coordinates changed. The gallery visibly distinguishes the normally faint closed options at native renderer scale and in the enlarged game-size crop.
