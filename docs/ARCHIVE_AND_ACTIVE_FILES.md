- Version-stamped older `docs/TEST_REPORT_*.md`, `docs/GAP_REGISTER_*.md`, `docs/qa_runs*/`, and `docs/history/changelogs/` hold prior regression evidence or agent handovers, **not current source-of-truth instructions**.

Therefore **no historical scripts, screenshots, source records or independently owned agent files were deleted in this checkpoint**. Only delete a file after a test-reference inventory, successful before/after full census and approval by the responsible workstream.
- `tests/.generated/`, local Python `__pycache__/`, Playwright temporary outputs and local browser caches are generated by tooling and should not be committed. Respect `.gitignore` if/when updated by their owner.
