# v0.6.0-alpha — Global Clubs & Career Expansion

- Added 6 confederation competition selectors and 151 continental participant club slots. Existing clubs reused, yielding 216 unique selectable teams.
- Added continental season logic (league/groups and knockouts, match simulation, qualification, local persistent progress and cup-prize tracking).
- Added six featured clubs to each tournament landing card with season and accuracy disclaimers.
- Opened manager careers to every included modern or continental club; added scouting/academy, recruit signing, fitness recovery, contracts, sponsorships, and regional league selections.
- Added Quick Match filters per home and away by country/club/continent/legends/category, so 216 entries are navigable.
- Added JSON save export/import from Settings to transfer career, tournaments, clubs and edits between PC/phone manually.
- Added deterministic championship regression suite and desktop/mobile Chromium interaction QA (continental campaigns, career and transfer processes, categorized match selection and JSON export/import dialogues).
- Added explicit gap audit so future development does not confuse arcade approximations, placeholder squads or procedural faces with finished authentic content.
