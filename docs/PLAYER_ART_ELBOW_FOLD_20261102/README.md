# Outfield elbow fold polish

## Scope

The idle game render showed the near outfield arm reading as one smooth tube through the elbow. Added one subtle inward crease to the near, non-goalkeeper elbow so its bend reads more clearly. The fold is skin-derived; it does not alter arm pose, hand drawing, kit, or keeper art.

Acceptance criteria:

- A small elbow fold appears on the near ordinary-player arm across skin tones.
- The far arm and all goalkeeper arm/glove poses remain unchanged.
- Actual renderer output stays nonblank, unclipped, and error-free.
