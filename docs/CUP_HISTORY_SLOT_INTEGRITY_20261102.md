# Cup history slot integrity — 2026-11-02

## Acceptance criteria

- Every stored Cup history row is a non-null, non-array object before save, preview, import, or restore.
- Malformed history is rejected before Cup storage changes.
- Valid history generated by league, group qualification, knockout, and bye events remains accepted.

## Change

`CUP_SLOTS.validTournament` and both standalone/modular `validateTournament` APIs now reject null, primitive, or array entries in the bounded history list. The tournament result view reads fields such as `stage` and `kind` from each history entry; a null entry from a hand-edited or rechecksummed backup or a legacy save could otherwise crash that view after restore.
