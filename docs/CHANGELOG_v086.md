# Changelog — Supermagic Football v0.8.6 (2026-10-13)

### Implemented
- Independent arcing bicycle shot through Jump + Dribble, including action-specific stamina and render pose.
- Defensive flying kick using Jump + Shoot when no assigned super move or aerial-ball action applies.
- Basic double-tap dribble trick with invulnerability window and cooldown.
- Keeper distribution, including human Pass control and timed CPU passing, with clear-passing HUD cue.
- Lateral AI route attempts when obstructed by ground players.
- Added four new UI/graphics backlog requirements (#181–184), explicitly after v0.8.7/0.8.8.
- Updated export version to 0.8.6; earlier browser save import compatibility preserved.

### Not included
Full ten-type dribble system, global character redraws, penalty movement, official icons, full AI pathfinding, online multiplayer.
