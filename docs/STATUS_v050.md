# Development status — 2026-10-13

**Current version:** v0.5.0-alpha. Original independent Canvas arcade soccer game; no emulator or ROM.

| User request | This release | Remaining gap |
|---|---|---|
| Unique cartoon player faces | Persistent name-seeded caricatures, 35+ illustration presets | Detailed commissioned/reconstructed portraits per player would improve resemblance |

| Comedic goal celebrations | 3.3-second visual confetti and players jumping/dancing | More distinct team/character celebration sequences |
| Possession-sensitive controls | Shoot→slide; pass→chase; special→body challenge | Deeper off-ball tactics and improved collision fidelity |
| 32 national teams (2026) | Included as editorial top-ranked 12-player selections | Official date-accurate national rosters/ratings needed |
| 32 major clubs (2026) | Included, 12 slots each | Club placeholders exist pending authoritative data |

| Player customization | Twelve face/appearance controls and saves | Full kit/height/body/movement editor planned |
| Manager career / clubs | Playable eight-club league and cup, training/transfers/facilities | Full world calendar, 32-team competitions, budgets, scouting, contracts, scheduling |
| PC/phone/browser | Offline self-contained HTML, desktop/mobile browser testing | Real phone + physical gamepad certification needed |
