# v0.8.4 Alpha — Changelog

- Removed center-screen super-shot toast (effects and sounds preserved).
- Four cross-positioned mobile actions replace six; responsive landscape-safe layout.
- Added contextual Dribble/Switch and dribble forward feint with stamina cost.
- Pass input now distinguishes tap, hold, and Jump+Pass cross.
- Jump-hold run, double jump, and owning-ball double-jump super shot introduced.
- Defensive Jump+Shoot prioritizes reachable rare GK/field abilities; aerial header and teammate combo supers preserved.
- Shooting aim chooses the goalkeeper's more open side when accuracy allows; inaccuracy adds noise.
- Delayed hands-off auto-switch only for clearly closer nearby teammates.
- Existing keyboard shortcuts retained during input migration. Backlog expanded with collision, tricks and custom bindings.
- Backward-compatible 216-team gameplay and career content preserved; testing documented separately.
