# Supermagic Football — preliminary public naming check
**Date:** 2026-10-13. **Scope:** public web discovery only; NOT trademark clearance.

- Exact searches for `"Supermagic Football"` and combinations with game/app/trademark did not show a clearly established existing video game with this exact title among reviewed results.
- Similar wording exists in unrelated sporting-goods listings: `NIVIA Super Magic Football Shoes` (https://www.flipkart.com/nivia-super-magic-football-shoes-men/p/itmf3xe7yyaupcvk). A historical `Uhlsport Super Magic Football` ball is also mentioned in reseller listings (https://www.bluebreaks.com/products/sir-stanley-matthews-signed-soccer-ball-football-england-blackpool-toronto-jsa-authenticated).
- Standalone **SUPERMAGIC** trademark entries are visible for goods such as cereals (https://trademarks.justia.com/browse-by-serial-number/98/72/30/); they cannot establish clearance for computer-game software in Sweden/EU.

**Decision:** use **Supermagic Football** as provisional internal/pre-release brand. Before commercial launch search the official EUIPO/TMview and PRV, WIPO Global Brand Database, relevant app stores, domain names, and jurisdictions, with professional review if required. A search result not finding a conflict is not proof of uniqueness.

**Migration:** old alpha name accepted in save import; `legend_*` storage keys retained; historic releases remain intact.
