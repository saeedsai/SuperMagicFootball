Supermagic Football v0.8.22.1 — Complete default game data CSV export

Source: verified /mnt/data/Supermagic_Football_v0.8.22.1_Clean_Handover.zip
Method: execute the same installExpansion, installContinentalClubs, withStats and installBPWWorldCups modules as the shipped game; export data with no browser localStorage.

One player row represents ONE TEAM ROSTER SLOT, not necessarily a unique real-life person. Same player may appear on multiple game teams. 222 teams x 12 slots = 2,664 rows.

'Raw' means the unmodified default roster object before withStats() hydration; 'effective' means the runtime withStats() object. The 14 1-100 effective stats and calculated positional OVR are generated by the game where unprovided in source. These are NOT independently verified FIFA / EA FC or Transfermarkt ratings.

Appearance columns describe the deterministic stylized character the renderer would create via avatarFor(), including preset hair/skin colors, eyes, brows, noses, lips, facial details, body build, stature and exaggeration. They are game-art parameters, NOT real-world biometric claims. Player customization stored in an individual user's browser, saved Career state, custom clubs, or saved roster edits cannot be read from this static project ZIP and are not in this export.

Nationality is only populated when supplied explicitly in a player record. Team flag/country and national-team affiliation are separate fields; a player's club does NOT establish their nationality.

Super ability type and eligibility are derived with the current withStats() rules. A level value of 1 with no super ability does NOT mean the player can perform a transformed super shot. The planned Gold/Star/Superstar tier/exclusivity changes are backlog-only and NOT represented as active rules.

All CSV files are UTF-8 with a BOM for better Excel compatibility. JSON columns use compact UTF-8 JSON strings so no source fields are lost. See 08_Data_Dictionary.csv.
